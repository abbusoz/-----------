# Coin Trade

Сайти савдои виртуалии крипто / Виртуальная торговля криптой / Virtual crypto trading demo.

- Воридшавӣ бо ном ва фамилия, интихоби забон (TJ / RU / EN)
- Кабинети шахсӣ, 100 коини виртуалӣ
- Нархҳои воқеӣ аз Binance (WebSocket, ҳар сония), графики зинда бо crosshair
- Интихобшудаҳо (★), харидан ва фурӯхтан бо коини виртуалӣ

Файлҳо: `index.html`, `style.css`, `app.js` — бе сервер ва бе кітобхона.

## Дар GitHub Pages ҷойгир кардан
1. Репозиторияи нав созед ва се файлро бор кунед.
2. Settings → Pages → Branch: `main` / root → Save.
3. Пайванд: `https://<username>.github.io/<repo>/`

## Эзоҳ
Маълумот дар `localStorage`-и браузер нигоҳ дошта мешавад (байни дастгоҳҳо умумӣ нест).
Нархҳо аз `data-api.binance.vision` / `data-stream.binance.vision` гирифта мешаванд. Ин лоиҳа барои таълим аст, на маслиҳати сармоягузорӣ.
